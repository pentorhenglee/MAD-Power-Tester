# POWER TESTER Booth

ตู้ท้าพลัง 3 ด่าน วิชา Microcontroller Application and Development กลุ่ม A-03

ตู้เกมแบบเดินเข้าไปเล่น มี 3 ด่าน กรี๊ดใส่ไมค์ ตบปุ่มที่ติดไฟ แล้วออกไปต่อยกระสอบหลังตู้ ตู้รวมคะแนน 3 ด่านแล้วแสดงบนจอทั้งสอง ใช้ NUCLEO-F767ZI สองบอร์ดคุยกันผ่าน UART

## โฟลเดอร์

| โฟลเดอร์ | บอร์ด | ทำอะไร |
|---|---|---|
| `BoxerBoothA/` | A | ตัวคุมเกม (state machine) ด่านตบปุ่ม จอ A กับทัช PIR |
| `BoxerBooth/` | B | ด่านกรี๊ด ด่านต่อย จอ B เสียง DFPlayer ไฟเส้น WS2812B |

บอร์ด A เป็นตัวสั่ง บอร์ด B ทำตามคำสั่งแล้วส่งคะแนนกลับ เพราะเซนเซอร์ของด่านกรี๊ดกับด่านต่อยอยู่ฝั่ง B

## ไฟล์หลัก

บอร์ด A (`BoxerBoothA/Core/Src`)

| ไฟล์ | หน้าที่ |
|---|---|
| `game.c` | ลำดับเกม IDLE ATTRACT INTRO COUNT RUN NEXT FINAL รับ EXTI ของทัชกับ PIR |
| `stage_smash.c` | ด่านตบปุ่ม สแกนปุ่มด้วย TIM6 ทุก 1 ms ไฟติดพร้อมกัน 3 ดวง |
| `stage_remote.c` | ด่านกรี๊ดกับด่านต่อยฝั่ง A สั่งบอร์ด B แล้วรอคะแนน |
| `pir.c` | ช่วงอุ่นเครื่อง 30 วิของ PIR |

บอร์ด B (`BoxerBooth/Core/Src`)

| ไฟล์ | หน้าที่ |
|---|---|
| `slave.c` | รับคำสั่งจากบอร์ด A แล้วรันด่าน เสียง ไฟ หน้าจอ |
| `adc_dma.c` | ADC1 สองช่อง (ไมค์ PA3 เพียโซ PC0) กับ DMA แบบวน |
| `stage_scream.c` | ด่านกรี๊ด คิด RMS ความดังแล้วสะสมพลังเสียง 10 วิ |
| `stage_punch.c` | ด่านต่อย ปุ่มเขียว จับหมัด คิดพื้นที่ใต้กราฟ |
| `sound.c` | สั่ง DFPlayer ผ่าน USART2 |
| `leds.c` | ไฟเส้น 60 ดวง ด้วย TIM3 PWM กับ DMA |

ใช้ทั้งสองบอร์ด: `link.c` (USART6 ส่งรับทีละบรรทัด) `hud.c` `img.c` `screens.c` (วาดหน้าจอ)

## เปิดโปรเจกต์

1. ใน STM32CubeIDE ไปที่ File > Import > Existing Projects into Workspace แล้วเลือกโฟลเดอร์ repo จะเจอสองโปรเจกต์
2. build แล้วแฟลชทีละบอร์ด `BoxerBoothA` ลงบอร์ด A `BoxerBooth` ลงบอร์ด B
3. การ์ด microSD ของ DFPlayer ต้องมีโฟลเดอร์ `mp3` ข้างในเป็น `0001.mp3` ถึง `0011.mp3`

## ต่อสาย

- UART ระหว่างบอร์ด: PG14 ของบอร์ดหนึ่งไป PG9 ของอีกบอร์ด ไขว้กัน และต่อ GND ร่วม
- ไฟเลี้ยงเข้าขา E5V (CN11 ขา 6) แล้วย้ายจัมเปอร์ JP3 ไปที่ E5V ห้ามจ่ายเข้าขา +5V
- เพียโซต้องผ่านวงจรหนีบแรงดันก่อนเข้า PC0
- ไฟเส้นใช้แหล่งจ่าย 5V แยก ต่อ GND ร่วมกับบอร์ด B

ขาทั้งหมดดูได้ในไฟล์ `.ioc` ของแต่ละโปรเจกต์

## โหมดเทส

ตั้งค่าใน `main.c` ปกติเป็น 0 ทั้งหมด = เล่นเกมจริง

| บอร์ด | ค่า | ใช้ทำอะไร |
|---|---|---|
| A | `DEMO_SCREENS` | ไล่ดูหน้าจอทั้งหมด |
| A | `TEST_PIR_ONLY` | เทส PIR ดูผลผ่าน serial |
| A | `DEBUG_PIR_LEDS` | เล่นเกมจริง แต่ให้ไฟบนบอร์ดบอกสถานะ PIR |
| B | `DEMO_SCREENS` | ไล่ดูหน้าจอทั้งหมด |
| B | `TEST_PUNCH` | เล่นด่านต่อยบนบอร์ด B ตัวเดียว โชว์ค่าดิบไว้คาลิเบรต |
| B | `TEST_SCREAM_ONLY` | เล่นด่านกรี๊ดตัวเดียว ดูค่าไมค์ผ่าน serial |
| B | `TEST_LEDS` · `TEST_SOUND` | เทสไฟเส้น · ไล่เล่นเสียงทุกไฟล์ |
| B | `TEST_SOUND_WITH_LEDS` | ใช้คู่กับ `TEST_SOUND` เปิดไฟเส้นพร้อมเพลง ไว้เช็กว่าไฟเส้นกวนไฟเลี้ยงของ DFPlayer ไหม |
| B | `DEBUG_LINK` | พิมพ์ข้อความที่รับจากบอร์ด A ออก serial |
